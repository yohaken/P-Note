# QA Checklist — Cream compact · โน้ตหน้าแรก · ไม่มีไอคอน

ตรวจใช้งานจริงทีละข้อ → ถ้า fail ให้จด bug + แก้จนผ่านก่อนข้อถัดไป  
เป้าหมายสุดท้าย: **เปิดแอปแล้วเห็นหน้างาน (ลิสต์โน้ต) จริง**

## A. โหลดหน้าแรก (ต้องผ่านก่อน)

- [ ] A1 เปิด `http://localhost:5000/` หรือ `/` แล้วไปที่ **โน้ต** (`note.html`) ไม่ค้างที่สุขภาพ
- [ ] A2 หน้าโหลดไม่ขาว/ไม่ error ใน console (module 404 / syntax)
- [ ] A3 เห็น topbar `P-Note` + แถบ **ค้นหาโน้ต…** บนหน้าแรก (ไม่ต้องกดไอคอนค้นหา)
- [ ] A4 พื้นหลังโทนครีมสว่าง (ไม่ม่วง / ไม่ดำเป็นค่าเริ่ม — ยกเว้นเคยตั้งมืดไว้)
- [ ] A5 แถบตัวกรองเป็นข้อความล้วน: กำหนด / ล่าสุด / ความสำคัญ / การซ้ำ / แท็ก — **ไม่มี emoji**
- [ ] A6 FAB เล็กลง (AI / แผ่นงาน / กลุ่มงาน) ไม่กินจอ

## B. ลิสต์โน้ต / หน้างาน

- [ ] B1 มีลิสต์โน้ต หรือ empty state “ยังไม่มีโน้ต” (ไม่ blank)
- [ ] B2 หัวข้อโน้ตในลิสต์ **ไม่มี emoji นำหน้า** (แม้โน้ตเก่ามี 📝)
- [ ] B3 แถวโน้ตแน่น/บาง (compact) อ่านหัวข้อ + preview ได้
- [ ] B4 แท็กซ้าย / due ขวา ยังใช้งานได้
- [ ] B5 แตะโน้ต → เปิด editor ได้ แล้วกลับลิสต์ได้

## C. ค้นหา (หาโน้ต)

- [ ] C1 พิมพ์ในช่องค้นหา → ลิสต์กรองทันที
- [ ] C2 ไม่พบ → ข้อความ “ไม่พบ …”
- [ ] C3 ปุ่ม × ล้างค้นหา → ลิสต์กลับมาครบ

## D. กลุ่มงาน / แผ่นงาน (สุขภาพเป็นรอง)

- [ ] D1 ปุ่ม ☰ → drawer: งาน / ทำแล้ว / ถังขยะ (ข้อความล้วน)
- [ ] D2 ค้าง ▦ → เมนูแผ่นงาน: **โน้ต** (หน้านี้) + **สุขภาพ** — ไม่มี emoji
- [ ] D3 แตะสุขภาพ → ไป Calorie ได้ · กลับโน้ตได้

## E. สร้าง / แก้โน้ต

- [ ] E1 ปุ่ม AI / จดว่าง → สร้างโน้ตได้
- [ ] E2 หัวข้อที่ AI สร้าง **ไม่มี emoji บังคับ**
- [ ] E3 บันทึกแล้วโผล่ในลิสต์หน้างาน
- [ ] E4 ลบ → ไปถังขยะได้

## F. ธีม / ความหนาแน่น

- [ ] F1 ตั้งค่า → สว่าง = ครีม · มืด = ดำ ยังสลับได้
- [ ] F2 สไลเดอร์ความหนาแน่นการ์ดยังขยับได้

## G. Regression สั้นๆ

- [ ] G1 Refresh หน้า → ยังอยู่หน้าโน้ต + ข้อมูลไม่หาย (local/offline ok)
- [ ] G2 ไม่มีปุ่มสุขภาพบน primary ของหน้าโน้ต
- [ ] G3 Build meta `pnote-build` = 124 (หรือใหม่กว่า)
