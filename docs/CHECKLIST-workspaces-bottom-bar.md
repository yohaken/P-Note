## Phase D — แผ่นงาน (workspaces) + sync

### ข้อมูล
- [ ] ขยาย payload → version 6: `workspaces[]`, โน้ตมี `workspaceId`
- [ ] migrate อัตโนมัติ: สร้างแผ่น **ทั่วไป** ผูกโน้ตเดิมทั้งหมด
- [ ] แท็กแชร์ทุกแผ่น (ไม่แยกต่อแผ่น)
- [ ] `lastWorkspaceId` ใน settings เครื่อง — เปิดแอปเข้าแผ่นล่าสุดที่ใช้
- [ ] กรองรายการ/ค้นหา/กลุ่มงาน ตามแผ่นที่เปิดอยู่
- [ ] บันทึกโน้ตยัง local-first + sync พื้นหลัง (merge ตาม `updatedAt`) ข้ามเครื่องเห็นชุดเดียวกัน

### UI
- [ ] Topbar แสดงชื่อแผ่นปัจจุบัน (เช่น `ทั่วไป ▾`) — แตะเปิดเมนูสลับแผ่น
- [ ] เมนู: รายการแผ่น + **+ แผ่นงานใหม่**
- [ ] กดค้างรายการแผ่น → rename
- [ ] ห้ามลบแผ่นถ้ายังมีโน้ต (active/done/trash ในแผ่นนั้น) — แจ้งเหตุผลชัด
- [ ] สถานะบันทึก: จุด/ปุ่มเขียวเล็กๆ ไม่สะดุดตา (บันทึกทันที / ซิงค์แล้ว)
- [ ] ทดสอบ: สร้างหลายแผ่น · สลับ · rename · เปิดแอปกลับมาแผ่นล่าสุด
- [ ] ทดสอบ sync: เครื่อง A สร้างโน้ตในแผ่น X → เครื่อง B เห็นแผ่น + โน้ตชุดเดียวกัน
